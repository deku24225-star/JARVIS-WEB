# JARVIS Web V1
Mobile-first JARVIS-style PWA prototype. Supports text, browser speech recognition/TTS where supported, English/Hindi settings, time/date, live weather, web search, YouTube, Maps, local memory, stop/mute, custom wake phrase mode, personality settings, confirmation-gated call/message handoffs, and offline caching.

For production Gemini/LLM use, add a secure backend endpoint. Do not expose an API key in browser JavaScript.

Serve over HTTPS (or localhost) for best browser support, then open on Android Chrome and use Add to Home screen.
